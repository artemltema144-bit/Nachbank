# Национальный Банк Ирновии (Нацбанк Ирновии)

Игровое банковское приложение для вымышленного государства **Царство Ирновия** в неподражаемом дизайне **Monobank** (темная неоновая тема, удобные 3D-карты, круглые кнопки перевода и выставления счетов).

## Возможности

1. **Регистрация и Вход (Монобанк Стиль):**
   - Интеграция с официальным государственным реестром паспортов через Google Apps Script по коду паспорта (например, `C•01•191125•001`).
   - Автоматическая привязка личных данных (ФИО, трудовая, судимости, Discord) и генерация уникального номера карты `4441...`.
   - Установка 4-значного PIN-кода для безопасности.
   - Вход по номеру карты или коду паспорта + PIN-коду.

2. **Главный экран банка:**
   - Интерактивная банковская карта с отображением баланса в национальной валюте **Жорон** (символ `}|{`).
   - Быстрая динамика баланса (график расходов для Царства Ирновия).
   - Кнопки быстрых действий (Перевод, Выставить счет, Добавить счет, Посмотреть паспорт).
   - Красивая история транзакций с разделением по цветам и типам операций (переводы, государственные выплаты, списания банкомата).

3. **Инвойсы и счета на оплату:**
   - Выставление счетов любому игроку по его коду паспорта или карте.
   - Красивое всплывающее пуш-уведомление для получателя ("Вам выставлен счет").
   - Выбор "Оплатить" или "Отклонить". При отклонении показывается модалка-предупреждение о последствиях обмана и уклонения по законам Ирновии.

4. **Личный Кабинет Работодателя:**
   - Подача заявки на регистрацию компании и одобрение администрацией банка.
   - Выпуск "Зарплатных" и "Пенсионных" карт сотрудникам по их коду паспорта.
   - Возможность списания средств без подтверждения (безусловный счет) для ведения легитимного бизнеса.

5. **Админ-Панель (Кабинет Банкира):**
   - Доступ по секретному коду `199235`.
   - **Снятие наличных:** списание с карты игрока с указанием номера отделения банка или банкомата.
   - **Государственные выплаты:** начисление Жоронов на карты игроков с указанием названия пособия и номера заявления.
   - **Список игроков:** просмотр балансов, выпущенных карт и транзакций всех граждан.
   - **Модерация бизнеса:** одобрение или отклонение компаний работодателей.

## Технологический стек

- **Фронтенд:** React 18, Vite, Tailwind CSS, Lucide React (иконки), Canvas Confetti.
- **База данных:** Supabase (включает self-healing автосохранение и полную отказоустойчивость: при отсутствии таблиц или сети приложение бесшовно переходит на локальное хранилище LocalStorage, гарантируя 100% работоспособность).

## Установка и запуск

1. Установите зависимости:
   ```bash
   npm install
   ```
2. Запустите в режиме разработки:
   `npm run dev &`
3. Соберите проект для публикации на Netlify:
   `npm run build`
